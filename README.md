# 기억 서재 — 실리태번판

[tlsiddl/marinara-memory-module](https://github.com/tlsiddl/marinara-memory-module) (MIT)의 장기 기억 모듈을 SillyTavern에서 쓸 수 있게 옮긴 확장입니다.
원작은 Marinara Engine 전용이며, 이 실리태번판은 원작자와 관계없는 비공식 포팅입니다.

기억을 정리하고 회상하는 로직(장면·챕터·큰 흐름, 알게 된 사실, 아직 끝나지 않은 일, 기한, 최근 생활, 회상, 기억 언어)은 원작 v0.11.10 코드를 **그대로** 쓰고,
Marinara에 붙던 부분만 실리태번용으로 바꿨습니다. 기억 서재 화면도 원작 그대로입니다.

## 설치

압축을 풀어 나온 `memory-library` 폴더를 실리태번의 `data/default-user/extensions/` 안에 넣고 새로고침하세요.
(서버 설정 파일은 고치지 않아도 됩니다.)

## 처음 설정

1. **기억 정리용 연결 프로필 만들기** — API 연결 메뉴에서 기억 정리에 쓸 모델(저렴하고 긴 글을 잘 읽는 모델, 예: DeepSeek, Gemini Flash)로 연결한 뒤 연결 프로필을 하나 저장합니다.
2. 화면 오른쪽 아래 **MEMORY 티켓 아이콘**(또는 확장 패널 → 기억 서재 → 기억 서재 열기)으로 기억 서재를 엽니다.
3. **설정 → 기억 정리에 쓸 연결**에서 그 프로필을 고르고 저장합니다.
4. 기억을 쓸 채팅을 열고, 기억 서재 왼쪽 아래 **이 방에서 기억 사용**을 켭니다.
5. **한눈에 → 이어서 정리**를 누릅니다. 처음에는 지난 대화 전체를 정리합니다.
6. 실리태번 **컨텍스트 크기**를 넉넉히 둡니다(3만 2천 토큰 이상 추천). 기억이 보통 1만~1만 5천 토큰입니다.

그다음부터는 답변마다 자동으로 정리되고, 답변을 만들 때 필요한 기억이 자동으로 들어갑니다.

## 원작과 다른 점

- **정리는 실리태번을 연 브라우저 탭에서 돌아갑니다.** 처음 정리(메시지 500개에 1시간 남짓)를 할 때는 탭을 열어 두세요. 중간에 닫아도 다음에 ‘이어서 정리’로 이어집니다.
- **기억 데이터**는 실리태번 서버의 `data/<사용자>/user/files/` 폴더에 `mm-`로 시작하는 파일로 저장됩니다.
- **기억 넣는 방법**: 기본은 자동(채팅 기록 바로 위). 설정 → 실리태번 연동에서 ‘매크로’로 바꾸면 프리셋에 직접 적은 `{{memory}}` 자리에만 들어갑니다(원작의 `{{기억}}`과 같은 역할).
- **원문으로 읽을 최근 메시지 수**(기본 30): 원작의 채팅 메시지 한도 역할입니다. 이보다 오래되고 이미 장면으로 정리된 메시지는 프롬프트에서 빼고 기억으로 대신합니다(설정에서 끌 수 있음).
- **뜻으로 찾기(임베딩)**: 실리태번은 API 키를 서버에만 두므로, OpenAI 호환 임베딩 주소·키·모델을 기억 서재 설정에 따로 넣습니다. 요청은 브라우저에서 바로 가므로 브라우저 요청(CORS)을 받는 서비스여야 합니다.
- **분기**: 실리태번에서 분기를 만들면 분기 지점까지의 기억을 이어받습니다.
- 말풍선 태그 되살리기(Marinara 전용 기능)는 없습니다.
